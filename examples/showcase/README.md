# 可手动上传的作品示例

- `optics.html`：折射、色散和斯涅尔定律。
- `motor.html`：通电线圈、电磁力矩和换向器示意。

这两份文件不再导入前端代码或作为内置模板。使用「成果殿堂 → 上传作品 → 添加交互 HTML → 上传 HTML 作品」选择文件，填写标题和封面后提交审核。管理员可通过作品编辑替换已有 HTML；学生修改后需要重新审核。

单文件内嵌全部样式和脚本，在隔离沙箱运行。底部说明在宽度大于 480px 时横排，手机窄屏改为纵排以保证可读性。

## 项目精选作品

`curated.json` 保存三件精选作品的标题、说明、分类、源文件和封面路径。均由本项目测试示例整理，统一署名 admin，作为平台公共作品发布，不关联学生或小组，不奖励能量币。

| 文件 | 内容 | 使用方式 |
| --- | --- | --- |
| `damped-oscillator.html` | 解析解驱动的弹簧振子，四种阻尼模式、相图、能量与位移曲线 | 上传交互 HTML |
| `helmholtz.obj` | d=R 的同轴双线圈、绕组、支架和中心探头 | 上传 3D 模型，选择 OBJ |
| `cyclotron.obj` | 开顶剖视的双 D 形电极、加速间隙和离子源 | 上传 3D 模型，选择 OBJ |

封面位于 `covers/`。模型是结构教学示意，不提供场强或粒子轨迹计算，也不作为制造图纸。振子使用 SI 单位、m=1 kg、初速度为零的线性弹簧与黏性阻尼模型，不代表真实实验数据。

这些文件沿用普通作品上传、编辑和审核流程，没有内置模板 ID 或前端导入。管理员上传公共作品后以 0 能量币通过审核；如使用学生账户上传，则归属该学生所在小组并需教师审核。

重建模型与原创封面：`python3 examples/showcase/build_curated.py`（需要 Pillow；字体优先 macOS 系统字体）。验证：`node examples/showcase/verify.cjs`。验证覆盖运动方程、初始条件、能量守恒/耗散、临界/过阻尼无过冲、OBJ 索引及三角化面积。浏览器与发布记录见 `docs/refactoring/CURATED-SHOWCASE-QA-2026-10-25.md`。
