## 沉浸式 UI 迭代

在上述布局重构基础上，加入深色半透明顶栏与导航、背景光晕和网格、分层毛玻璃卡片、页面标题光环，以及错峰进入的任务卡片。移动端缩短品牌标题；动画遵循系统的减少动态效果偏好。样式集中在 `src/design-system/styles/immersive.css`，跨页面共享的卡片与壳层只增加少量语义类名。改版后的[六场景截图](screenshots/2026-10-09-immersive/README.md)与原版目录并存，便于对照。

本次迭代通过 `npm run build`；六个截图场景均无页面 JS 错误、重复壳层或横向溢出。另在 390px、系统“减少动态效果”模式下确认背景动画停止，手机导航可进入知识星系页面。

## 聚焦式卡片首页

学生默认首页改为 Hero、当前项目与下一学习阶段两张主卡、四个任务入口；完整学习路径、榜单、动态与班级统计保留在 `?view=overview` 视图。教师默认首页改为 Hero 指标和审核、课题、小组三张工作卡；原指标、图表、预警与流水保留在 `?view=analytics`。管理控制台用四张工作区卡片代替横向标签，首次进入先选择工作区。卡片导航支持键盘进入，详情视图可返回聚焦首页。

[聚焦式截图及运行报告](screenshots/2026-10-09-focused/README.md)包含学生、教师、管理员的默认页，学生手机页，以及两种详细视图。实测学生/教师的详细视图进入与返回、管理员工作区切换均无 JS 页面错误。

最终构建通过；八个截图场景均无重复壳层、页面 JS 错误或横向溢出。另在 390px 和 768px 视口验证无横向溢出，并通过键盘 Enter 从学生任务卡片进入知识星系。当前页面文件仍有原有 ESLint 问题（如旧代码的 `any`、未使用状态与 Hook 依赖警告），本批新增的入口组件和键盘交互不依赖这些问题。
