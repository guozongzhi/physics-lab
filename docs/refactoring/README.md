## 核心决策

保留 React、Vite、FastAPI、SQLAlchemy 和现有部署方式。前端以业务领域组织代码，统一布局、组件和状态反馈；服务端负责业务事实和能量币结算，前端只保留交互状态及有明确范围的缓存。后端采用模块化单体，先建立边界，再考虑扩展。

预计一名熟悉项目的开发者需要约 24–36 个工作日，包含验证和数据迁移演练；这是规划估算，阶段 0 后应重新估计。课堂使用期间分批交付，每批都能单独回退。
