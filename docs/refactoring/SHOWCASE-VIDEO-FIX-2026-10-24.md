# 成果展示视频修复与测试记录（2026-10-24）

## 修复范围

1. Compose 将 VIDEO_UPLOAD_DIR 指向已有 db-data 卷内的 /data/showcase-videos。
2. Nginx /api/ 请求体允许 101 MiB，容纳 100 MiB 文件及 multipart 边界；后端文件限制仍为 100 MiB。
3. 视频播放先通过 Bearer 登录申请文件级凭证，有效期 2 小时。凭证不含 sub，不能作为站点登录凭证使用。每个播放/Range 请求重新检查用户及作品权限，拒绝匿名、跨组未审核访问；审批撤回和删除后其他组的旧凭证失效。上传旁保存所属用户 JSON，未绑定草稿仅上传者可预览。旧文件通过已有作品关联校验，无所属元数据且未绑定的文件默认拒绝。
4. 上传前（包括封面提取）锁定提交；关闭、切换分类或编辑另一作品时取消上传，忽略迟到结果。切换账号后不写回旧结果。视频地址在上传时不可编辑；封面提取最多等待 5 秒，不阻塞上传。

## 部署迁移（不可直接重建旧容器）

旧版本视频位于容器 /app/uploads/videos，切换配置前必须先备份并迁移。保持原文件名，作品数据库链接无需更改。

1. 暂停上传入口，确定旧 backend 容器 ID；在重建前将 /app/uploads/videos 导出至宿主机备份（若使用自定义目录，使用实际目录）。
2. 同时备份 /data 数据库及已有持久化文件。
3. 在旧容器内创建 /data/showcase-videos，将导出的所有视频和 JSON 元数据复制进去；校验数量及 SHA-256 与备份一致。该路径必须确认为现有持久化卷。
4. 完成迁移后再部署新前后端和 nginx 配置；如外层还有代理，同步允许大于 100 MiB 的 multipart 请求。
5. 验证旧视频、草稿预览、教师审核、2 MiB 及接近 100 MiB 上传、拖动播放；重建一次 backend 后再次验证文件。
6. 回滚保留数据库和文件备份，不删除持久化卷。正式数据不应被本轮隔离测试覆盖。

本轮没有修改云端、运行迁移、提交或推送代码。
