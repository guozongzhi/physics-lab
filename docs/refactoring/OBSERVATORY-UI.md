# 观测站风格全站重构

日期：2026-10-11。以工作区现有登录页为视觉基准，修改均留在本地，未提交或部署。

## 页面与视觉

学生、教师、管理员共用观测站背景、深蓝导航、冰蓝玻璃卡片、蓝色主操作与统一表单、表格、弹窗样式。手机使用登录页的竖版背景和抽屉导航。样式集中于 `src/design-system/styles/workspace.css`，原有登录页和登录素材改动予以保留。

浏览器检查范围：1440×900 桌面、390×844 手机。12 个学生主页面、7 个教师主页面和管理员页面的 4 个工作区均可加载，检查范围内无页面横向溢出。路由报告保存在 [截图目录](screenshots/2026-10-11-observatory/)。动态测验页另有答题与交卷验证。

## 功能补齐与修正

- 页面搜索支持按钮和 Cmd/Ctrl+K，按当前角色展示入口；补上知识擂台导航、品牌返回首页、导航当前项、跳过导航链接。
- 学习主题 URL 可直达，非法或未解锁主题会回到可学习主题。学习与成绩统计只计当前用户的有效记录。
- 知识星河支持全部学科、搜索、章节层级难度筛选、空结果提示及键盘选点。关联题来自已有题库；综合练习创建真实测验会话后进入答题页。跨章节前置节点连接已修正。
- 知识点自评掌握、浏览阶段记录、个人目标按用户在本设备保存。自评掌握和浏览记录明确区别于测验成绩，不计入服务器成绩。
- 看板学习阶段依据浏览、个人测验、小组项目、挑战、能量流水与审批结果计算。个人档案移除固定示例等级、经验、挑战奖励和虚假目标完成状态。
- 在线模式不再初始化演示身份；修复在线用户登录后刷新被本地演示数据覆盖的问题。隔离测试数据库验证了教师与学生刷新后的角色和身份。
- 修复答题时在 React 状态更新器内修改另一个 store 的警告。
- 共享弹窗使用 portal，避免页面动画容器裁切；支持标题、焦点循环、Esc、恢复焦点、手机高度限制。手机导航支持关闭按钮、焦点限制和滚动锁定；复选框 ID 稳定且有键盘焦点提示。
