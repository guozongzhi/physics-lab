# 光学与电机独立 HTML Demo

将公共光学、电机演示制作为自包含 HTML，保留深色实验台、参数控制、动态 SVG、实时读数、原理卡片和重置。无外部脚本、样式、字体或图片依赖，可下载后独立打开，也可导入成果上传窗口。

- 公共演示新增“下载 HTML Demo”；文件为 optics-demo.html、motor-demo.html。
- 上传作品 → 添加交互 HTML → 可选择“追踪一束光的旅程”和“让线圈开始转动”。
- 切换模板时更新模板默认标题与简介，用户手动修改的内容保留。
- 原公共作品的作者、审批状态和业务数据不变。
